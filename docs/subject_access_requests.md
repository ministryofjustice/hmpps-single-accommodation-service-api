# Subject Access Request

## Overview

Each service in HMPPS that owns/manages data must be able to produce a Subject Access Report on-demand.

HMPPS provide an API definition that is used to produce this report in a standard way. The API exposes two endpoints:

- `GET /subject-access-request` - given a CRN or PRN, returns JSON used to generate a SAR report
- `GET /subject-access-request/template` - returns a mustache template that can render a report given the aforementioned JSON (see `src/main/resources/sar/template_hmpps-single-accommodation-service-api.mustache`)

We have several integration tests related to SAR (under `src/test/kotlin/.../integration/sar/`), leveraging the testing tools provided by https://github.com/ministryofjustice/hmpps-subject-access-request-lib

For more information on SAR, see the [SAR confluence pages](https://dsdmoj.atlassian.net/wiki/spaces/NDSS/pages/6057492792/Subject+Access+Request+-+HMPPS+Digital)

## Making Changes

Whenever the data model changes (e.g. Flyway schema updated or JPA data model is changed), we should consider if we want to update the SAR data and/or template.

Note - just because we add a data field doesn't necessarily mean we need to add it to the SAR. See the [SAR confluence pages](https://dsdmoj.atlassian.net/wiki/spaces/NDSS/pages/6057492792/Subject+Access+Request+-+HMPPS+Digital) for more information.

There are tests in `SarSchemaChangeDetectionTest` that 'catch' changes to the Flyway schema or JPA data model, acting as a prompt to the developer to consider SAR updates. Once that decision has been made, fix these tests by running `./gradlew updateSarSchemaTrackers`.

When the SAR data or template changes, the fixtures used by `SarComplianceTest`  (in `src/test/resources/sar`) need regenerating. Run `./gradlew updateSarFixtures` and review the changes.

### Change Control

Whenever the SAR data and/or template is updated we need to follow an 'offline' change control process **before any changes are merged to main/deployed**. This process is documented on the [SAR confluence page](https://dsdmoj.atlassian.net/wiki/spaces/NDSS/pages/6057492792/Subject+Access+Request+-+HMPPS+Digital).

As part of this approval a sample PDF report will be requested. This can be generated by running `./gradlew generateSarPdf`.

### Template Modifications

* There is specific guidance to follow regarding what should go in the template, as certain data types should be formatted/presented in certain ways
  * Functions are provided to help with formatting and presentation. See the [SAR confluence pages](https://dsdmoj.atlassian.net/wiki/spaces/NDSS/pages/6057492792/Subject+Access+Request+-+HMPPS+Digital)
